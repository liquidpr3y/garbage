# MITRE ATT&CK®

`enterprise.json` is generated from MITRE's published `enterprise-attack` STIX
bundle (see `docs/PHASE4.md` for the regeneration script). It is a reduced form:
technique IDs, names, tactics, sub-technique parents, platforms, revocation
mappings, and the log sources and Sysmon event codes MITRE associates with
detecting each technique.
